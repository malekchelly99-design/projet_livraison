# Configuration Firebase - Livraison Rapide

Ce projet est configuré avec Firebase (`livraison-6f112`).

## Plateformes configurées

- **Android** : `com.example.livraison_rapide`
- **iOS** : `com.example.livraisonRapide`
- **macOS** : `com.example.livraisonRapide`
- **Web** : `livraison_rapide (web)`
- **Windows** : `livraison_rapide (windows)`

La configuration se trouve dans [`lib/firebase_options.dart`](lib/firebase_options.dart) et a été générée via FlutterFire CLI.

---

## Comment exécuter l'application

### 1. Sur le Web (Google Chrome)
```bash
flutter run -d chrome
```

### 2. Sur Android (Émulateur ou Appareil connecté)
Assurez-vous qu'un émulateur est démarré ou un smartphone Android en mode débogage USB est connecté :
```bash
flutter run -d android
```

### 3. Compilation des exécutables
- **Web** :
  ```bash
  flutter build web
  ```
- **Android APK** :
  ```bash
  flutter build apk --debug
  ```

1. **Firebase Authentication** : Connexion par Email & Mot de passe.
