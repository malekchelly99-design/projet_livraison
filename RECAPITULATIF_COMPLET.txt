───────────────────────────────────────────────────────────────
                    PROBLEMES FREQUENTS
───────────────────────────────────────────────────────────────

PROBLEME : "No Firebase App has been created"
SOLUTION : Exécutez flutterfire configure

PROBLEME : "Permission denied" dans Firestore
SOLUTION : Configurez les règles de sécurité Firestore

PROBLEME : "Invalid API key"
SOLUTION : Vérifiez que firebase_options.dart contient 
           de vraies clés (pas "VOTRE_XXX")

PROBLEME : Application affiche écran d'erreur rouge
SOLUTION : C'est normal ! Firebase n'est pas encore configuré.
           Suivez les étapes ci-dessus.

PROBLEME : Script PowerShell ne s'exécute pas
SOLUTION : Utilisez la méthode manuelle avec flutterfire configure
