ÉTAPE 1 : Configurer Firebase
------------------------------
Ouvrez PowerShell dans ce dossier et tapez :

    .\configure_firebase.ps1

Ou manuellement :

    dart pub global activate flutterfire_cli
    flutterfire configure


ÉTAPE 2 : Activer les services Firebase
-----------------------------------------
1. Allez sur https://console.firebase.google.com/
2. Sélectionnez votre projet
3. Activez "Authentication" → Email/Password
4. Créez "Firestore Database" → Mode production


ÉTAPE 3 : Configurer les règles Firestore
------------------------------------------
Copiez les règles depuis le fichier :
    → DEMARRAGE_RAPIDE.md (section "Règles de Sécurité")

Dans Firebase Console :
    → Firestore Database → Règles → Collez → Publier


ÉTAPE 4 : Tester l'application
-------------------------------
    flutter clean
    flutter pub get
    flutter run -d chrome
